# Real-Time Sign Language Detector (A–Z)

A real-time American Sign Language (ASL) alphabet recognition pipeline built using Python, MediaPipe, OpenCV, and Scikit-Learn.

## Features
- Multi-class gesture detection covering letters **A through Z** (26 classes).
- Hand landmark extraction using MediaPipe (42 normalized feature points).
- Real-time webcam inference using a Random Forest Classifier.
